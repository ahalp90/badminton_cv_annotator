# Original investigation records

These files preserve the first two experiment iterations and the additive
correction pass. They retain the names and terminology used while the work was
active.

Use `../ARCHIVE_MAP.md` to find a record. Use `../../README.md` for the current
decision and `../../report.md` for the reconciled narrative.

`original_experiment_code.zip` preserves the original experiment layout. Its
imports refer to the former top-level paths. The archived worklog names the
commits to use for an exact runnable checkout.
