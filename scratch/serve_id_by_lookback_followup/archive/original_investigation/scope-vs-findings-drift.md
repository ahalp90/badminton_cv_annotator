# Scope reconciliation

This note is historical. The user subsequently settled the experiment in
`00_SHARED_CONTRACT.md` and `01_LAUNCH_ACCEPTED_CONTACT_TRACE.md`. Those later
rulings control.

The earlier findings had replaced backwards origin tracing with a shortcut:
classify the first accepted impulse from incoming motion alone. That was not the
requested experiment.

The corrected experiment has both movements:

1. Start at the first accepted impulse and move forward only past impulses with
   usable post-contact evidence that they lack outgoing motion.
2. Once a credible contact has incoming motion, trace the incoming trajectory
   backwards. Reinspect any accepted contact identified as its origin.

`incoming motion` does not by itself imply an unshown serve. The rule may infer
an unshown serve only when a usable backwards trace finds no accepted origin.
Unavailable evidence returns `not enough shuttle trajectory to tell`.

Run the same ground-truth-free rule on all 239 rallies. Score it afterwards.
The 97 currently unmatched first impulses are a failure slice for analysis, not
the population that decides whether the rule runs.

The original `Scope.md` remains provenance for the initial request. Where it
differs from the later rulings above, the later rulings apply.
