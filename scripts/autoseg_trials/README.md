# autoseg_trials

Frozen run-time originals of the s27-s29 contact-detection and rally-segmentation trial harnesses, committed so they stop living in throwaway /tmp worktrees. These are versioned records, not tooling: they were written to run from a worktree root with sys.path seams and their outputs beside them, so re-running them needs path adjustments. The numbers they produced live in the campaign readouts (docs migration pending; currently Ariel-local under local_scratch/autograder_architecture/).

- `scripts/archive/m_sticky_gate_arm.py` / `scripts/archive/m_sticky_gate_arm_r7.py`: s27 sticky-anchor gate arms at suppression radius 9 / 7
- `scripts/archive/m_miss_junk_census.py`: s27 miss census and junk-signal quartiles
- `scripts/archive/s27_promotion_pin.py`: md5 pin for the pre-swap chain; FAILS BY DESIGN since the s28 sticky swap (frozen record)
- `scripts/archive/s28_sticky_pin.py`: DEPRECATED P-era acceptance pins, both radii (r9 pilot ddc4f60b / vid15 e0fa8941; r7 c259e147 / c332cfb2). Kept byte-frozen as the pre-base-30 record; FAILS BY DESIGN on the base-30 tree. Superseded by `scripts/archive/s28_sticky_pin_r30.py`
- `scripts/archive/s28_sticky_pin_r30.py`: acceptance pins re-earned after the fps constants flipped to base-30 integers (r9 pilot d4f60a1a / vid15 117920c2; r7 684e0c10 / 304c09f5). Note the r9 arm no longer matches the H yardstick record (b9988d38 / a977890b): the shipped chain's default suppression radius at 25 fps scales to 8 under base-30, so the pre-flip coincidence between "default" and "radius 9" is gone. Run recipe: copy to a worktree root beside a copy of `scripts/archive/h_end_to_end.py`, with measurements/ on PYTHONPATH.
- `scripts/archive/h_end_to_end.py`: end-to-end yardstick driver (console record: h_end_to_end_console_s28.txt). It binds an absolute wt_s24 worktree path at import, so repoint it when reusing. The old path silently runs the old tree.
- Protected current harness, kept separate from those seven archived records: `scripts/autoseg_trials/s28_sticky_pin_anchor_picks.py`. Its four comparison CSVs remain under `scripts/autoseg_trials/s28_sticky_pin_anchor_picks_outputs/`; it binds the checkout relative to the script, passes scene-gated sticky distances into `segment_video`, and runs radius 9 before radius 7. The current end-to-end scoring yardstick uses its default radius 8 at 25 fps, so these CSVs are comparison records, not expected md5s.
- s28_sticky_measure.py: the four-cell sticky measurement. This historical P consumer imports the archived pin and miss-census modules by their old local names, so re-running it needs archive-path adjustments.
- s29_sweep_measure.py: the 95/95 burst_ratio x visible-run filter sweep (this is the re-earn copy that produced the record CSVs; the builder's copy differed only cosmetically). This historical P consumer also needs archive-path adjustments.
